# 개발자 둘리

**바이브코딩으로 개발하고 있는 비전공자 개발자입니다.**

저는 바이브 코딩으로 개발에 입문한 비전공자입니다. **폭넓은 기술적 경험**을 쌓으며, **AI마다 가진 강점과 한계를 이해하고, 작업에 맞는 모델과 도구를 선택해 조합하는 것**을 중요하게 생각합니다. 특정 언어나 프레임워크에 머무르기보다 해결하려는 문제를 기준으로 기술 스택을 고르고, 기획부터 개발·검증·배포까지 직접 이끌어 가며 풀스택 프로젝트를 완성하고 있습니다.
